# 📦 Installation

Clone the repository.

```bash
git clone https://github.com/yourusername/ai-backend-portfolio.git
```

Go into the project.

```bash
cd ai-backend-portfolio
```

Install dependencies.

```bash
npm install
```

Start development server.

```bash
npm run dev
```

Open:

```text
http://localhost:3000
```

---

# ⚙️ Environment Variables

NEXT_PUBLIC_EMAILJS_SERVICE_ID=
NEXT_PUBLIC_EMAILJS_TEMPLATE_ID=
